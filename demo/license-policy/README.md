# License policy demonstration

This draft PR demonstrates the repository's agentic license policy and must
not be merged.

The first revision contains only this original documentation. It provides
the clean control for a genuine agent-produced successful review.

A later revision will add the pinned upstream QEMU radio machine source,
preserving its attribution and license. That revision is expected to fail
because a project-level Apache license does not override the source file's
own copyleft license grant.

The demonstration source is not part of the firmware build.
