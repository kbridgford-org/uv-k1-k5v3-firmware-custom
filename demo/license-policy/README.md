# License policy demonstration

This demonstration PR illustrates the repository's agentic license policy
and must not be merged.

The menu label change in `App/ui/menu.c` gives the emulator review a visible
screen change to verify.

The pinned upstream QEMU radio machine source is included to show how the
license review handles a newly added copyleft file. The repository-level
Apache license does not override the source file's own license grant.

The demonstration source is not part of the firmware build.
